# Teacher Attendance & Verification System — Supabase Edition

This version is a complete conversion of the supplied project from MongoDB/Mongoose to Supabase PostgreSQL.

## Stack
- Flutter frontend
- Node.js + Express backend
- Supabase PostgreSQL
- `pg` for database access
- Socket.IO
- JWT authentication
- Multer photo upload
- Provider on Flutter

## 1. Supabase setup
1. Create a free Supabase project.
2. Open **SQL Editor**.
3. Run `backend/supabase/schema.sql`.
4. Open **Connect** and copy the Session Pooler PostgreSQL connection string.
5. Open **Project Settings → API** and copy Project URL and keys.

## 2. Backend
Copy `.env.example` to `.env` and set:
- `DATABASE_URL`
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `JWT_SECRET`

Then:
```powershell
cd backend
pnpm install
pnpm run dev
```

Test:
`http://localhost:5000/health`

## 3. First admin
The normal register route is protected. For first setup, create an admin directly in Supabase SQL using a bcrypt hash generated by the backend, or temporarily remove the admin middleware from `/api/auth/register`, register once with `"role":"admin"`, then restore it.

A simple development method:
```powershell
node -e "require('bcryptjs').hash('admin123',12).then(console.log)"
```
Copy the resulting hash into Supabase:
```sql
insert into users(name,email,password_hash,role)
values ('Admin','admin@example.com','PASTE_BCRYPT_HASH_HERE','admin');
```

## 4. Flutter
```powershell
cd frontend
flutter pub get
flutter run
```

Set the API base URL in `frontend/lib/config/api_config.dart`.
- Android emulator: `http://10.0.2.2:5000/api`
- iOS simulator: `http://localhost:5000/api`
- Physical phone: `http://YOUR_PC_LAN_IP:5000/api`

## Important
The supplied source did not include complete Android/iOS platform folders or Firebase configuration files. Those cannot be safely fabricated because Firebase provides project-specific files. Run `flutter create .` inside `frontend` to generate the platform folders, then add your Firebase files and permissions.

This project contains no real Supabase passwords, API keys, Firebase credentials, or service-role secrets.
